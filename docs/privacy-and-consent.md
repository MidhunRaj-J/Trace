# Privacy and Consent (MVP)

## Consent Rules

- Explicit opt-in before any collection starts.
- Explain exactly what is collected and why.
- Allow pause/resume and revoke consent at any time.

## Data Minimization

- Keystroke: store timing features, never characters.
- Voice: store only required signal features and session metadata for scoring.
- Remove or rotate direct identifiers.

## User Controls

- Export personal data summary.
- Delete all data by user request.
- Show last collection time and active sensors.

## Clinical Framing

- Product language must avoid diagnosis claims.
- Surface trend and confidence, not deterministic labels.
- Encourage qualified clinical follow-up for concerning trends.
